# Google Maps Platform APIs required (enable in Google Cloud Console):
#   Geocoding API       — address → lat/lng
#   Directions API      — routes between two points
#   Places API          — nearby police, hospitals, safety centres
#   Maps Static API     — static map image URL for Flutter Image.network()
#
# Get your API key: https://console.cloud.google.com/google/maps-apis/credentials
# Set it in:        map-backend/.env  (copy from map-backend/.env.example)

# Backend endpoints served at http://localhost:8000 :
#   GET /health                — liveness probe
#   GET /api/geocode           — address → lat/lng
#   GET /api/routes            — safety-ranked routes (Safest/Fastest/Scenic)
#   GET /api/nearby-help       — police, hospitals, women safety centres
#   GET /api/static-map-url    — Static Maps URL for Flutter Image.network()
